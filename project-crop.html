Machine Learning (PG Project)

Crop Yield Prediction

Satellite‑driven crop yield estimation using NDVI, precipitation, temperature and land‑surface data, with Random Forest as the deployed model and a Flask web app for state‑wise predictions and remedies.

Overview

The system fuses satellite‑derived indicators with climate variables to forecast regional yields. It emphasizes reliable preprocessing, feature engineering, and an interpretable UX that surfaces predicted yield, level (low/medium/high), and contextual factors.

My Role

I handled dataset curation (NDVI, temperature, precipitation, land surface), model benchmarking, Random Forest tuning, Flask integration, MySQL persistence, and the web UI for state selection and remedy generation.

Key Features

State‑aware predictions, yield level classification, dynamic remedies, secure login/signup, and export‑ready summaries. Designed to scale across regions and crops.

Tech Stack

Python (Flask), scikit‑learn (Random Forest best), Pandas/NumPy, MySQL, HTML/CSS/JS. Data sources include NDVI and climate features.

Outcome

Delivered a robust prediction pipeline and web interface with strong R² and low error metrics for Random Forest, demonstrating practical value for planners and farmers.
