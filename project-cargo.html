Web Application (UG Project)

Cargo Management System

A web-based platform to streamline logistics workflows, improve shipment visibility, and support bulk cargo operations for a simulated transport company.

Overview

Built as a full-stack application with a focus on clean UI and reliable data flow, the system centralizes cargo records and operational tasks. It provides inventory tracking, shipment management, and reporting to reduce manual effort and errors.

My Role

I led end-to-end development—front-end screens, form validations, server-side modules, and database design—ensuring consistent UX and maintainable code.

Key Features

Shipment lifecycle tracking from booking to delivery, bulk cargo workflows, role-based access for staff and admin, and searchable logs with export-ready summaries.

Tech Stack

HTML, CSS, JavaScript for the UI; PHP/ASP for server logic; MySQL for persistence; deployed on a LAMP-style setup during development.

Outcome

Delivered a cohesive system that demonstrates practical CRUD design, modular code structure, and clear separation of concerns suitable for logistics operations.
