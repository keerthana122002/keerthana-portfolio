IoT Application (PG Project)

Smart Irrigation System

An IoT‑driven irrigation solution built with NodeMCU ESP8266, soil‑moisture sensing, and Blynk app control to reduce water wastage and automate field watering with real‑time visibility.

Overview

The system monitors soil moisture continuously and actuates a relay‑controlled water pump when values fall below a calibrated threshold. It centralizes field data and streamlines irrigation decisions with minimal manual intervention.

My Role

I built the end‑to‑end prototype, covering sensor integration, firmware logic, Blynk dashboard setup, and documentation, while focusing on stability, calibration, and clean UX for remote control.

Key Features

Real‑time soil moisture telemetry, automatic pump control, manual override from mobile, alerts for critical states, and extensible multi‑zone architecture for larger fields.

Tech Stack

NodeMCU ESP8266, soil moisture sensors, relay module, Arduino IDE firmware, Blynk IoT dashboard, and optional cloud logging for trends.

Outcome

A reliable IoT irrigation workflow that cut manual checks, optimized watering cycles, and demonstrated practical automation suitable for sustainable farming scenarios.
